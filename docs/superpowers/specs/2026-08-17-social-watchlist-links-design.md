# 社媒白名单与检索入口设计

## 目标

将已整理的 100 个 AIGC、数字艺术、漫剧和 IP 账号纳入日报项目的白名单，并提供可点击的核验入口；不改变“免费、纯规则、无社媒自动抓取”的边界。

## 方案

新增独立的 `social_watchlist.json`，每条包含：唯一标识、平台、账号名、领域、类型、搜索词、检索链接、是否已启用采集。

- 公众号条目使用微信公开搜索链接。
- 小红书条目使用小红书站内搜索链接；已有小红书号的个人创作者以其 ID 为搜索词。
- 全部条目初始 `enabled: false`。检索入口用于人工核验，绝不被采集器当作 RSS 或正文来源。

## 网页表现

日报首页新增“关注账号白名单”折叠区：按四个领域展示账号名、平台、类型和“打开搜索”链接，并注明“未接入自动抓取”。

## 数据流与失败处理

`social_watchlist.json` 是网页展示唯一数据源。生成日报时读取它并渲染，不请求这些链接；链接失效不会影响新闻采集、日报生成或定时工作流。

## 验证

1. 白名单恰好为 100 条。
2. 每条均有有效的 HTTPS 检索链接、领域和平台。
3. 页面显示 100 条入口；原有采集和两项单元测试仍通过。
